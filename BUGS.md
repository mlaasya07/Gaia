# Bugs found

Every item here was reproduced or confirmed in the code. Status is **Fixed** (with the version that fixed it) or **Open**.

| #   | Bug                                                                                                                     | Impact                                                                                                 | Fix                                                                                        |
| --- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |

| 5   | Each route created its own simulation                                                                                   | Clock, alerts and overrides disagreed between pages                                                    | One shared simulation (`SimProvider`) at the root                                          |
| 6   | The Safety agent label was unreadable (dark red text on a dark background)                                              | An agent was effectively invisible in the panel                                                        | Text color changed to a readable token                                                     |

## Open: findings in the research results

These are not code defects. They are limits of the trained models that anyone presenting Gaia should know.

| #   | Finding                                                                                 | Evidence                                                                                                                    |
| --- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| R1  | The learned policy rarely beats the centralized baseline on reward                      | Wins in 5 of 30 held-out runs; latency is worse in 30 of 30                                                                 |
| R2  | The learned policy is nearly constant                                                   | Maintenance always on, cloud offload always off, shift always on over 2,880 steps; only production level moves (about 0.60) |
| R3  | The agents do not show learned communication                                            | Every attention cell is between 0.243 and 0.259 (an even split is 0.25)                                                     |
| R4  | Real-dataset conditioning did not help                                                  | Simulator-only checkpoint scores reward 0.248 against 0.237 for the real-data checkpoint                                    |
| R5  | The simulator-only checkpoint cannot be re-run with the current code                    | Only its saved metrics appear on the Research page                                                                          |
| R6  | The Python negotiating agents score lower reward than centralized MPC and siloed agents | Default condition: 0.21 to 0.29 against 0.49 to 0.50; they use far less energy but deliver less throughput                  |
| R7  | Pretraining the negotiating agents did not raise reward                                 | Pretrained variants score below the static and cold-start variants                                                          |

## Open: gaps

| #   | Gap                                                               | Note                                                                                                                                                                                                    |
| --- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G1  | Roles are not security                                            | There is no login or server; anyone can switch role. This is stated in the app and docs                                                                                                                 |
| G2  | Simulation state is lost on reload                                | By design; reset and reload both clear it                                                                                                                                                               |
| G3  | Layouts were not checked by eye in this release                   | The light theme was verified by WCAG contrast calculations and tests, and every route was loaded on the dev server, but no browser screenshots were taken. Please look through each page in both themes |
| G4  | Backend tests were not re-run for this release                    | PyTorch is required and was not installed in the build environment                                                                                                                                      |
| G5  | Three different agent sets share the LACD name                    | Live twin: 7 agents. Evidence experiments: 5. Learned policy: 4. Documented in `Details.md`                                                                                                             |
| G6  | Several techniques from the referenced papers are not implemented | MAPPO with an attention critic, generative augmentation, federated learning, meta-learning, causal discovery                                                                                            |
